# Documentation graphics

The SVG files in this directory are original conceptual figures for the repository README:

- `digital_twin_architecture.svg` — hybrid data, model, decision, and evidence layers;
- `thermal_control_loop.svg` — two-state RC thermal model and scenario loop.

They are not data-derived results and must not be interpreted as achieved forecast accuracy, calibrated building physics, or observed equipment degradation. Data-driven figures are written to `outputs/figures/` only after local experiments have run.
